# DutchCharger – Dodge Charger Sebring Police

Website voor Unit 2101: een voormalige politieauto uit Sebring, Florida, nu in Nederland.
Gewone HTML/CSS/JS – geen installatie nodig. Open `index.html` in je browser.

## Zelf aanpassen
Pagina's: `index.html` (home), `dossier.html`, `apparatuur.html`, `evenementen.html`, `huren.html`.

- **Foto's**: zet ze in `images/`. Elk grijs vak op de site toont de bestandsnaam die het verwacht
  (bijv. `hero.jpg`, `dossier.jpg`, `toen.jpg`, `nu.jpg`, `spotted-1.jpg`). Zodra het bestand er staat, verschijnt de foto.
- **E-mailadres en social links**: bovenaan `js/main.js` (`SETTINGS`).
- **Menu en footer**: staan één keer in `js/main.js` en worden op alle pagina's gebruikt.
- **YouTube-filmpje** (Springfield Police): zie de opmerking in `evenementen.html`.
- **Teksten**: elke tekst staat er twee keer in: `<span lang="nl">` en `<span lang="en">`.

## Online zetten
Kan gratis via GitHub Pages of Netlify, daarna eigen domein (bijv. dutchcharger.nl) koppelen.
