# DutchCharger – Dodge Charger Sebring Police

Website voor Unit 2101: een voormalige politieauto uit Sebring, Florida, nu in Nederland.
Gewone HTML/CSS/JS – geen installatie nodig. Open `index.html` in je browser.

## Zelf aanpassen
- **Foto's**: zet ze in `images/` met deze namen (vervangen dan automatisch de placeholders):
  - `hero.jpg` – grote achtergrond bovenaan (liefst 's nachts met lichten aan)
  - `dossier.jpg` – "politiefoto" in het dossier (staand)
  - `toen.jpg` / `nu.jpg` – veilingfoto vs. nu (zelfde hoek, liggend)
  - `spotted-1.jpg` t/m `spotted-6.jpg` – galerij
- **E-mailadres** voor boekingen: bovenaan `js/main.js` (`CONTACT_EMAIL`).
- **Social links**: onderaan `index.html` bij `socials`.
- **Teksten**: elke tekst staat er twee keer in: `<span lang="nl">` en `<span lang="en">`.

## Online zetten
Kan gratis via GitHub Pages of Netlify, daarna eigen domein (bijv. dutchcharger.nl) koppelen.
